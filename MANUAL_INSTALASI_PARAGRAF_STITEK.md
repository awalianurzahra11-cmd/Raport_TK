### 4.1.3. Manual Instalasi

Manual instalasi memuat uraian komprehensif mengenai tahapan-tahapan proses pemasangan, konfigurasi basis data, serta prosedur eksekusi sistem aplikasi E-Raport Taman Kanak-Kanak (TK) Inklusi Anak Berkebutuhan Khusus (ABK) pada komputer pengguna di sekolah tempat penelitian dilaksanakan. Penyusunan dokumentasi cara instalasi ini bertujuan agar pihak sekolah, baik tenaga administrasi sekolah maupun guru pendamping khusus, dapat melakukan proses instalasi dan implementasi sistem secara mandiri dengan mudah tanpa harus menghubungi pihak pembuat program (*programmer/system analyst*).

Sebelum proses instalasi dimulai, perangkat komputer yang digunakan di sekolah harus memenuhi spesifikasi minimum perangkat keras dan perangkat lunak yang dipersyaratkan. Dari segi perangkat keras, komputer server maupun klien membutuhkan prosesor setara Intel Core i3 dengan kecepatan minimal 2.0 GHz, kapasitas memori utama (RAM) sekurang-kurangnya 4 GB, ruang kosong media penyimpanan minimal 5 GB, resolusi layar monitor minimal 1366 × 768 piksel, serta ketersediaan kartu antarmuka jaringan nirkabel (Wi-Fi) atau LAN untuk komunikasi data. Dari segi perangkat lunak, sistem beroperasi pada sistem operasi Microsoft Windows 10 atau 11 (64-bit), sistem manajemen basis data (*Database Management System*/DBMS) MySQL versi 8.0 atau MariaDB yang terpasang melalui paket Laragon atau XAMPP, *runtime environment* Python versi 3.10 atau 3.11 untuk backend FastAPI, *engine* Node.js versi 18 LTS beserta Node Package Manager (NPM) untuk frontend React Vite, serta peramban web modern seperti Google Chrome atau Microsoft Edge.

Tahap awal instalasi dilakukan dengan mempersiapkan DBMS MySQL sebagai media penyimpanan data relasional sistem. Pada lingkungan operasional sekolah, instalasi DBMS dilakukan dengan mengunduh paket bundel Laragon edisi *Full* atau paket XAMPP melalui situs web resminya masing-masing, kemudian menjalankan berkas *installer* biner dengan hak akses administrator (*Run as administrator*). Proses instalasi diselesaikan dengan mengikuti instruksi standar sistem, dilanjutkan dengan membuka panel kontrol aplikasi tersebut dan menekan tombol *Start All* pada Laragon atau tombol *Start* pada modul MySQL di XAMPP. Keberhasilan aktivasi layanan basis data ditandai dengan indikator modul MySQL yang berubah menjadi hijau dan beroperasi pada *port* bawaan 3306.

Tahap berikutnya adalah penyiapan lingkungan *runtime* untuk backend dan frontend pada komputer sekolah. Instalasi Python versi 3.10 atau 3.11 dilakukan dengan menjalankan berkas penginstal biner dari situs resmi Python, di mana pengguna wajib memberi tanda centang pada opsi *Add python.exe to PATH* pada jendela awal instalasi agar perintah Python dan pengelola paket *pip* dapat dikenali secara global oleh sistem operasi melalui jendela baris perintah (*Command Prompt*). Setelah proses instalasi Python selesai, instalasi Node.js versi 18 LTS dilakukan dengan mengeksekusi berkas *installer* biner (.msi) sesuai pengaturan standar. Keberhasilan pemasangan kedua komponen *runtime* tersebut kemudian diverifikasi melalui jendela *Command Prompt* dengan mengeksekusi perintah *python --version*, *pip --version*, *node -v*, serta *npm -v*.

Seluruh modul aplikasi, berkas skema basis data, konfigurasi lingkungan, serta skrip otomasi peluncur dikemas ke dalam satu paket direktori terpadu (*setup package*) bernama *APK rapot tk*. Struktur paket yang diserahkan ke pihak sekolah memuat direktori *backend* yang mengelola logika bisnis berbasis FastAPI, direktori *frontend-react* yang memuat antarmuka pengguna berbasis *Single Page Application* (SPA), direktori *database* yang berisi skema SQL dan skrip *setup*, berkas konfigurasi parameter lingkungan *.env*, berkas daftar dependensi pustaka *requirements.txt*, serta rangkaian berkas otomasi eksekusi berupa skrip *batch* yang meliputi *setup_database.bat*, *start_all.bat*, *start_backend.bat*, dan *start_frontend.bat*.

Proses inisialisasi basis data aplikasi dilaksanakan dengan memanfaatkan skrip otomasi *setup_database.bat* yang terdapat di dalam folder utama paket aplikasi. Ketika berkas tersebut diklik ganda, sistem secara otomatis mengeksekusi modul program Python *database/setup_db.py* yang terhubung ke layanan MySQL lokal. Skrip tersebut secara terstruktur membentuk basis data baru bernama *raport_tk* dengan set karakter *utf8mb4*, mengompilasi seluruh skema tabel entitas yang mencakup tabel pengguna, siswa, catatan jurnal harian, penilaian evaluasi perkembangan BK, rekap penilaian berkala, dokumen asesmen capaian, serta galeri kegiatan pembelajaran. Selain membentuk struktur relasi antar tabel, skrip ini juga secara otomatis menginjeksi data pengguna awal (*data seeding*) dengan kata sandi yang telah dienkripsi menggunakan algoritma *Bcrypt*, sehingga basis data langsung siap digunakan setelah muncul konfirmasi status selesai pada layar terminal.

Tahap selanjutnya adalah pemasangan seluruh dependensi pustaka yang dibutuhkan oleh sistem backend dan antarmuka frontend. Pada bagian backend, pemasangan dependensi dilakukan dengan membuka terminal *Command Prompt* pada direktori utama aplikasi, lalu mengeksekusi perintah *pip install -r requirements.txt* guna mengunduh dan memasang modul-modul penting seperti FastAPI, Uvicorn, SQLAlchemy, PyMySQL, Cryptography, dan ReportLab. Pada bagian frontend, pengguna berpindah ke dalam subdirektori *frontend-react* melalui terminal dan menjalankan perintah *npm install* hingga seluruh pustaka antarmuka seperti React 19, Lucide React, Tailwind CSS, serta Recharts selesai diunduh dan tersimpan ke dalam direktori *node_modules*.

Penyesuaian konfigurasi parameter lingkungan dilakukan melalui berkas *.env* yang terletak pada direktori utama sistem backend serta berkas *.env* pada direktori antarmuka frontend. Pada berkas *.env* backend, parameter *DATABASE_URL* dikonfigurasikan agar sesuai dengan alamat dan kredensial akses layanan MySQL lokal sekolah, termasuk penyesuaian jika kata sandi MySQL dikosongkan. Berkas tersebut juga memuat kunci rahasia (*SECRET_KEY*) dan masa berlaku token akses untuk mengamankan proses otentikasi berbasis *JSON Web Token* (JWT). Sementara itu, pada berkas *.env* di direktori frontend, parameter *VITE_BACKEND_URL* diarahkan ke alamat penyedia layanan API backend, yaitu *http://localhost:8000*.

Prosedur untuk menjalankan aplikasi dirancang sangat praktis agar dapat dioperasikan dengan mudah oleh staf sekolah tanpa memerlukan pengetikan perintah yang rumit di terminal. Pihak sekolah cukup mengklik ganda berkas eksekusi *start_all.bat* yang berada di direktori utama aplikasi. Berkas *batch* tersebut akan mengaktifkan skrip pengendali *run_dev.py* yang secara serentak membuka dua layanan utama, yaitu server backend FastAPI pada *port* 8000 dan server pengembangan antarmuka Vite React pada *port* 5173. Setelah kedua layanan beroperasi, pengguna dapat langsung membuka peramban web dan memasukkan alamat *http://localhost:5173* untuk mengakses seluruh antarmuka sistem E-Raport. Pihak sekolah maupun penguji juga dapat memeriksa dokumentasi interaktif pengujian *Application Programming Interface* (API) melalui alamat *http://127.0.0.1:8000/docs*.

Sistem E-Raport ini juga mendukung implementasi jaringan lokal multi-perangkat (*multi-device local deployment*) di lingkungan sekolah, di mana komputer server diletakkan di ruang tata usaha dan para guru pendamping mengakses sistem menggunakan laptop masing-masing melalui sambungan Wi-Fi sekolah. Konfigurasi dilakukan dengan memeriksa alamat IPv4 komputer server melalui perintah *ipconfig* pada jendela *Command Prompt*. Alamat IP server tersebut kemudian didaftarkan pada parameter *VITE_BACKEND_URL* pada berkas konfigurasi antarmuka klien, dan server frontend dijalankan dengan parameter jaringan *npm run dev -- --host*, sehingga seluruh guru pendamping dapat membuka sistem secara simultan melalui peramban web pada alamat IP server yang telah ditentukan.

Keberhasilan seluruh rangkaian instalasi diverifikasi dengan melakukan proses masuk (*login*) perdana ke dalam aplikasi menggunakan akun bawaan yang telah disediakan oleh sistem. Sistem menyediakan akun peran Administrator dengan surel *admin@rapor.tk* dan kata sandi *admin123* untuk mengakses fitur master data, manajemen pengguna, asesmen BK, dan pencetakan raport fisik, serta akun peran Guru Pendamping dengan surel *pendamping@rapor.tk* dan kata sandi *pin123* untuk pencatatan aktivitas harian dan pengisian narasi perkembangan anak. Apabila dalam proses pemasangan terjadi kendala teknis, penanganan dapat dilakukan secara sistematis, seperti memastikan layanan MySQL telah aktif pada panel kontrol jika terjadi penolakan koneksi basis data, menyesuaikan kata sandi pada berkas *.env* jika terjadi galat otentikasi, menjalankan perintah *Set-ExecutionPolicy RemoteSigned* pada Windows PowerShell jika eksekusi skrip dibatasi oleh kebijakan keamanan Windows, serta memastikan server backend telah berjalan sempurna sebelum antarmuka pengguna dibuka guna mencegah timbulnya pesan kesalahan komunikasi jaringan.
